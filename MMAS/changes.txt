// to keep up with my changes concerning making this a shippable software. 


I've turned the token stuff into a proper PKCE OAuth flow. no more client secret, no more manually copying codes out of the URL bar.

there's now a local callback server that catches the redirect, with a headless fallback that prints the URL and asks for the code. tokens get saved encrypted with Fernet instead of plain json, and the file gets chmod 600.

refresh is automatic now, tracking accessExpiresAt and refreshExpiresAt so it refreshes before things break instead of after. state and PKCE verifier are generated with secrets for CSRF protection.

client id comes from getClientId() in config now instead of being hardcoded.
